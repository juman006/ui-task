    HTML, CSS & JavaScript

    The web platform is built on three complementary technologies. Each has a distinct job, and together they form every page you browse.

    HTML

    HTML (HyperText Markup Language) provides the structure of a page: headings, paragraphs, links, images, and forms. It gives the browser a document to render and gives assistive tools something meaningful to read.

    CSS

    CSS (Cascading Style Sheets) controls presentation: layout, color, spacing, typography, and responsiveness. It lets the same HTML adapt to different screen sizes and themes without changing the markup.

    JavaScript

    JavaScript adds behavior. It runs in the browser to respond to user interaction, fetch data, and update the page without a reload.

    How they work together

    A browser parses HTML into the DOM, applies CSS rules to determine how each element looks, and then runs JavaScript to modify both over time. Changing text, hiding an element, or reacting to a click all rely on this pipeline.
